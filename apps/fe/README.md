# Ticket Box Frontend (Next.js + shadcn/ui)

Web frontend for the **Ticket Box** ticketing and event management system, built with [Next.js](https://nextjs.org/) 16 (App Router) and [shadcn/ui](https://ui.shadcn.com/).

---

## 📁 Project Structure

```text
apps/fe/
├── public/                 # Static assets (favicons, SVGs, images)
├── src/
│   ├── app/                # Next.js App Router (pages, layouts, route handlers)
│   │   ├── layout.tsx      # Root layout (Metadata, Google Fonts, theme providers)
│   │   ├── page.tsx        # Minimal starter homepage
│   │   └── globals.css     # Tailwind v4 theme tokens and imports
│   ├── components/         # Reusable component directory (UI primitives installed on demand)
│   │   └── ui/             # Atomic components generated by shadcn/ui CLI
│   ├── lib/
│   │   └── utils.ts        # Helper utility `cn()` (clsx + tailwind-merge)
│   └── types/              # TypeScript interface & type definitions
├── .dockerignore           # Docker build ignore rules
├── .env.example            # Sample environment variables
├── .yarnrc.yml             # Yarn Berry configuration (nodeLinker: node-modules)
├── components.json         # shadcn/ui CLI configuration
├── Dockerfile              # Multi-stage production container build
├── eslint.config.mjs       # ESLint configuration
├── next.config.ts          # Next.js configuration (standalone output enabled)
├── package.json            # Package definitions & scripts
├── tsconfig.json           # TypeScript configuration
├── yarn.lock               # Immutable Yarn lockfile
├── AGENTS.md               # Architecture rules & guidelines for AI assistants
├── DESIGN.md               # Design system tokens, color palettes, and UX specs
└── README.md
```

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) 16 (App Router, Turbopack, React Server Components)
- **Library**: [React](https://react.dev/) 19 & TypeScript 5
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) & [tw-animate-css](https://github.com/jamiebuilds/tw-animate-css)
- **UI System**: [shadcn/ui](https://ui.shadcn.com/) (Atomic components installed on demand)
- **Package Manager**: [Yarn Berry](https://yarnpkg.com/) 4.x (`nodeLinker: node-modules`)
- **Theme**: Light & Dark mode support via CSS Variables (OKLCH color system)

## 🐳 Docker & Docker Compose

### 1. Full Stack via Docker Compose
From the repository root:
```bash
# Start all services (Database + Backend + Frontend)
docker compose up -d

# View Frontend logs
docker compose logs -f frontend

# Stop all services
docker compose down
```

### 2. Standalone Docker Image
```bash
# Build standalone Docker image
docker build -t ticket-box-fe:latest .

# Run Frontend container standalone (accessible on http://localhost:3000)
docker run --rm -p 3000:3000 ticket-box-fe:latest
```

## 🚀 Getting Started

### Prerequisites
- **Node.js**: Version `>= 20.0.0`
- **Yarn Berry**: Version `4.x` (enabled automatically via `corepack enable`)

### Installation & Setup

1. Navigate to the frontend directory:
   ```bash
   cd apps/fe
   ```

2. Enable Corepack and install dependencies with Yarn Berry:
   ```bash
   corepack enable
   yarn install
   ```

3. (Optional) Set up local environment variables:
   ```bash
   cp .env.example .env.local
   ```

4. Start development server:
   ```bash
   yarn dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the application.

## 🧩 Adding UI Components with shadcn/ui

No pre-installed UI components are bundled by default to keep the repository lightweight. Install components on demand using the official CLI:

```bash
# General syntax
npx shadcn@latest add <component-name>

# Example: adding button, dialog, or table
npx shadcn@latest add button
npx shadcn@latest add dialog
npx shadcn@latest add table
```

Installed components are placed into `src/components/ui/` and can be customized directly.

## 🔌 Connecting to the Go Backend (`apps/be`)

The Go backend API runs at `http://localhost:8080`.

All API responses from `apps/be` follow the standard JSON envelope:

```json
{
  "code": 200,
  "message": "success",
  "data": { ... }
}
```

For paginated resources:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "items": [ ... ],
    "pagination": {
      "page": 1,
      "page_size": 10,
      "total_items": 42,
      "total_pages": 5
    }
  }
}
```

To configure the API endpoint, create `.env.local` from the provided `.env.example`:
```bash
cp .env.example .env.local
```

Inside `.env.local`:
```env
NEXT_PUBLIC_API_URL=http://localhost:8080/api/v1
NEXT_PUBLIC_APP_URL=http://localhost:3000
```
